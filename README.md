# JANY BEAUTY — catálogo

Projeto estático atual da JANY BEAUTY, pronto para subir no GitHub Pages ou no Netlify.

## Conteúdo

- `index.html` — página completa, com CSS embutido e imagens incorporadas no próprio HTML.
- `manifest.webmanifest` — configuração para instalação como aplicativo.
- `netlify.toml` — configuração simples de publicação no Netlify.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `manifest.webmanifest`, `netlify.toml` e este README para a raiz do repositório.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, selecione a branch principal e a pasta `/root`.
4. Salve e aguarde a publicação.

## Publicação no Netlify

Arraste esta pasta para o Netlify ou conecte o repositório do GitHub. O arquivo `netlify.toml` já define a raiz como diretório publicado.

## Observação importante sobre o painel administrativo

Este ZIP contém o catálogo público atual. O login administrativo com banco de dados e autenticação real ainda não está incluído, porque o projeto atual é estático. Não há senha gravada no HTML. Para adicionar o painel com segurança, será necessário conectar um serviço de autenticação/banco de dados ao projeto.

## Identidade preservada

O pacote mantém o layout atual, a identidade visual, os produtos, os catálogos de O Boticário, Eudora, Natura, Home Style e Avon, os links do WhatsApp e o guia em PDF.
